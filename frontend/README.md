# Resume AI Frontend

This is the frontend application for Resume AI, a web application that processes resumes and returns cat videos/images.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The application will be available at [http://localhost:3000](http://localhost:3000).

### Building for Production

To create a production build:

```bash
npm run build
```

The build artifacts will be stored in the `build/` directory.

## Features

- Drag and drop resume upload
- Support for PDF, DOC, and DOCX files
- Real-time upload status
- Grid view of processed resumes with cat content
- Responsive design

## Technologies Used

- React
- TypeScript
- Material-UI
- React Dropzone
- Axios
